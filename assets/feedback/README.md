# Customer feedback media

Place only real, approved customer media in these folders:

- `videos/customer-feedback-01.mp4`
- `posters/customer-feedback-01.webp`

Keep the shared number identical for each video/poster pair. Add the matching entry to
`js/feedback.js`; optional customer name, event type, and caption values may be left empty.
The page assigns a video source only after the visitor opens its card.
